# VitalDash

- Backend: Java
- Frontend: Angular
- Projektleiter: Mohamed Selmurzaev

## Struktur (geplant)

- `backend/`  Java-Backend (Import, Benutzerverwaltung, REST-API)
- `frontend/` Angular-Frontend (Dashboard, Diagramme)
